  PROJECT FOLDER STRUCTURE:
  --------------------------
  Final Project\
  |-- inputs\
  |   |-- covers\        <-- Put your cover images/videos here
  |   |-- secrets\       <-- Put your secret images/videos here
  |-- outputs\
  |   |-- stego_images\  <-- Stego outputs are saved here
  |   |-- extracted\     <-- Recovered secrets are saved here
  |   |-- results\       <-- Graphs and dashboards saved here
  |-- steganography_framework\
  |-- DEMO_COMMANDS.txt

---------------------------------------------------------------------
  IMAGE STEGANOGRAPHY
---------------------------------------------------------------------

STEP 1 - EMBED (Hides secret inside cover image + generates evaluation graph)
------------------------------------------------------------------------------
python -m steganography_framework.main embed --cover "inputs\covers\008_kingfisher-881594_640.jpg" --secret "inputs\secrets\al_khalid_l1.jpg" --output "outputs\stego_images\kingfisher_stego.png" --evaluate

  >>> IMPORTANT: After running the above, the console will print:
      Generated Key (hex):   <COPY THIS>
      Generated Nonce (hex): <COPY THIS>
      Save both values before continuing to Step 2!

  >>> OUTPUT FILES:
      - outputs\stego_images\kingfisher_stego.png
      - outputs\results\image_evaluation_results.png


STEP 2 - EXTRACT (Recovers secret + generates Dashboard + Comparison Grid)
---------------------------------------------------------------------------
python -m steganography_framework.main extract --stego "outputs\stego_images\kingfisher_stego.png" --key "PASTE_YOUR_KEY_HERE" --nonce "PASTE_YOUR_NONCE_HERE" --output "outputs\extracted\extracted_secret.jpg" --cover "inputs\covers\008_kingfisher-881594_640.jpg" --secret "inputs\secrets\al_khalid_l1.jpg" --visualize

  >>> OUTPUT FILES:
      - outputs\extracted\extracted_secret.jpg
      - outputs\results\evaluation_dashboard.png
      - outputs\results\comparison_grid.png

---------------------------------------------------------------------
  PERFECT METRIC REFERENCE (What to aim for)
---------------------------------------------------------------------

  BER (Bit Error Rate)  -->  Perfect = 0.0         (lower is better)
  SSIM                  -->  Perfect = 1.0         (higher is better, aim > 0.98)
  PSNR                  -->  Perfect >= 40 dB      (higher is better, > 50 dB = excellent)
  MSE                   -->  Perfect = 0.0         (lower is better)
  Recovery Rate         -->  Perfect = 100%        (use properly sized payload)
